# electronic_optical_bubble_sensor_panasonic
This is a 3D space-claim model of the Panasonic BE-A Optical Bubble Sensor, designed for small-diameter tubes.


Note: All dimensions in the detailed drawings are in inches.

I modeled this by strictly following the official technical data and reference drawings provided in the Panasonic datasheet. However, please note that manufacturers do not publish every single internal dimension (such as the exact tolerance of the snap-fit tube gap). For the information that was not provided, I carefully predicted and estimated the geometry to ensure the overall mounting footprint and space-claim remain highly accurate for assembly purposes.
